SABLE is a top-down stealth game set in a moonlit gallery: sneak past patrolling guards and their vision cones, hide behind crates, statues and hedges, crouch in shadow pools where you are hard to spot, lift every moon-gem, and slip out the exit unseen. Running is fast but loud — nearby guards hear it and come to look. Being seen fills a guard's suspicion meter; a full meter means a chase, and getting caught costs a life. Three galleries, three guards growing to four, keyboard and mouse play (WASD / arrows or click-to-move, Shift to run, C to crouch, H for a hint). No assets, no network — every picture and sound is drawn and synthesized in code, and the game runs fully offline from static files. Open `game/index.html` in a desktop browser to play.

## Run it

```sh
node main.ts
```
